## 🚀 Featured Projects

### 🌦️ ClimaTrip --- Smart Travel & Marine Analytics Platform

**Java 17 · Spring Boot 3 · Spring WebFlux · Spring Security · JWT ·
WebSockets · MySQL · OpenAI API**

-   Built an asynchronous backend with Spring WebFlux and `WebClient` to
    fetch and aggregate geocoding, weather, and ocean telemetry data.
-   Developed a multi-variable safety scoring engine using wind, wave
    height, and UV index for activities such as swimming, surfing,
    boating, and diving.
-   Implemented authentication and role-based authorization using Spring
    Security, JWT, and BCrypt.
-   Integrated OpenAI API for itinerary generation and WebSockets for
    real-time alerts.

### 📄 ResumeAnalyser --- AI Resume & ATS Optimization Engine

**Java 21 · Spring Boot 3 · Spring AI · OpenAI API · Apache Tika · REST
APIs**

-   Integrated Apache Tika to extract text from PDF and DOCX resumes.
-   Built an AI-powered pipeline to compare resumes with job
    descriptions and return ATS relevance scores, matched keywords, and
    missing keywords.
-   Used structured JSON prompting to generate resume-quality
    evaluations and actionable improvement suggestions.

### 🧪 Fake Review Detection --- Machine Learning

**Python · TF-IDF · Scikit-learn · Logistic Regression**

-   Explored text classification techniques to distinguish fake and
    genuine product reviews.
-   Used text preprocessing and TF-IDF feature extraction to convert
    review text into machine-learning features.
-   Evaluated classification performance using accuracy, precision,
    recall, and F1-score.
